# 修复记录：向导区「推荐路线」小地图不显示

日期：2026-10-27
涉及文件：`style.css`、`app.js`、`index.html`

---

## 一、问题现象

在首页「不知道去哪？问问清远。」一栏输入需求点「开始推荐」后：

- 推荐文案、`🧭 推荐路线：1. xxx → 2. xxx …`、toast「已在地图高亮 N 个推荐点位」都正常出现
- 但文字下方那块区域**始终是空白的黄色背景**，看不到地图
- 诡异现象：**只有按下 F12 打开开发者工具后，地图才显示出来**

---

## 二、根因（关键）

`.recommend-panel` 是一个 **flex 弹性布局容器**（`style.css:53`）：

```css
.recommend-panel { grid-column: 1 / -1; display: flex; flex-wrap: wrap; align-items: center; justify-content: space-between; gap: 35px; padding: 38px clamp(25px, 6vw, 86px); background: #f2d477; }
```

而地图容器 `.guide-map` 作为它的子项**没有声明宽度**。flex 子项的宽度默认「跟随内容」，但地图画布创建之前内容是空的，于是它被收缩到**只剩左右两条边框 = 2px 宽**。

实测证据（画布真实尺寸）：

```
画布 2x300  显示 2x300  容器 2x300
```

高度 300px 是对的，宽度只有 2px —— 一条 2 像素的细线，肉眼自然以为「没显示地图」。

**为什么按 F12 就显示**：打开 DevTools 会改变页面可视区域，触发浏览器重新排版并触发高德的 `resize`。这一次重排时画布里已经有内容，它的宽度才被撑开，地图就露出来了。这个现象把排查方向误导成了「渲染时序问题」。

---

## 三、修复内容

### 1. `style.css` —— 让地图容器独占整行（真正的修复）

改前：

```css
/* AI 向导区内嵌小地图：height/opacity 显隐（display 不切换，避免高德渲染器暂停） */
.guide-map { height: 0; opacity: 0; overflow: hidden; border-radius: 14px; margin-top: 0; border: 1px solid rgba(25,43,42,.2); transition: height .3s ease, opacity .3s ease, margin-top .3s ease; }
.guide-map.visible { height: 300px; opacity: 1; margin-top: 14px; }
```

改后：

```css
/* AI 向导区内嵌小地图：旧版用 height 过渡显隐，地图会在动画中途尺寸下初始化而画不出来；
   现在地图是「需要时才创建」，容器隐藏时根本没有实例，因此直接用 display 显隐，
   保证创建瞬间容器就是最终尺寸 */
.guide-map { display: none; width: 100%; flex-basis: 100%; height: 300px; overflow: hidden; border-radius: 14px; margin-top: 14px; border: 1px solid rgba(25,43,42,.2); }
.guide-map.visible { display: block; }
```

要点：

- `width: 100%` + `flex-basis: 100%`：**修复的关键**，地图占满整行，不再被 flex 收缩成 2px
- 去掉 `height: 0 → 300px` 的 0.3s 过渡，改用 `display` 显隐，创建瞬间布局就是最终尺寸
  （原本不能用 `display: none` 是因为地图实例一直存在会暂停渲染；现在地图改成懒创建，隐藏期间根本没有实例，所以可以安全使用）

### 2. `app.js` —— 地图改为懒创建（不再在 0 尺寸容器里初始化）

改前（页面加载时就创建，此时容器高度为 0）：

```js
const guideMap = new AMap.Map("guideMap", { zoom: 12, center: [113.056, 23.6818], viewMode: "2D", mapStyle: "amap://styles/normal", useNativeMap: true });
```

改后：

```js
// 向导区路线小地图：容器平时 height:0，此时创建实例会得到 0×0 的空白画布且不会自动恢复，
// 因此改为懒创建——等容器真正展开到目标高度后再实例化（见 drawRoute 里的 ensureGuideMap）。
// useNativeMap: 强制用 Canvas2D 渲染——绕开 Windows Chrome 的 WebGPU
// requestAdapter 二次调用失败（"No available adapters"）导致的空白画布
let guideMap = null;
function ensureGuideMap() {
  if (!guideMap) {
    guideMap = new AMap.Map("guideMap", { zoom: 12, center: [113.056, 23.6818], viewMode: "2D", mapStyle: "amap://styles/normal", useNativeMap: true });
  }
  return guideMap;
}
```

### 3. `app.js` —— `drawRoute()` 同步创建并强制首次重绘

```js
function drawRoute(spots) {
  clearRoute();
  if (spots.length < 2) return;
  const ordered = orderRouteSpots(spots);
  const path = ordered.map((spot) => [spot.lng, spot.lat]);
  // ……（路线文字、清除按钮）
  const container = document.querySelector("#guideMap");
  if (container) container.classList.add("visible");
  // 容器此时已是最终尺寸（display 显隐，无高度动画），可直接创建地图
  const gm = ensureGuideMap();
  // 路线画在向导区小地图上（主地图只高亮）：虚线连接 + 序号标记
  routeOverlay.polyline = new AMap.Polyline({ path, strokeColor: "#2F80ED", strokeWeight: 5, strokeOpacity: 0.85, strokeStyle: "dashed", showDir: true, zIndex: 80 });
  gm.add(routeOverlay.polyline);
  ordered.forEach((spot, index) => {
    const badge = new AMap.Marker({ position: [spot.lng, spot.lat], content: `<div class="route-badge">${index + 1}</div>`, offset: new AMap.Pixel(-13, -40), zIndex: 110 });
    gm.add(badge);
    routeOverlay.badges.push(badge);
  });
  gm.setFitView(null, false, [40, 40, 40, 40]);
  // 强制首次绘制：高德在尺寸未变化时会跳过重绘，轻推 1px 再还原可立刻触发绘制
  const nudgeRepaint = () => {
    window.dispatchEvent(new Event("resize"));
    if (!container) return;
    container.style.height = "301px";
    requestAnimationFrame(() => {
      container.style.height = "";
      gm.resize();
    });
  };
  nudgeRepaint();
  setTimeout(nudgeRepaint, 400);
}
```

### 4. `app.js` —— `clearRoute()` 增加空值保护（配合懒创建）

```js
function clearRoute() {
  if (routeOverlay.polyline && guideMap) { guideMap.remove(routeOverlay.polyline); routeOverlay.polyline = null; }
  if (guideMap) routeOverlay.badges.forEach((badge) => guideMap.remove(badge));
  routeOverlay.badges = [];
  // ……
}
```

### 5. `app.js` —— 新增本地验证开关 `?demoRoute=1`（无需后端即可验证地图）

```js
// 本地验证开关：访问 index.html?demoRoute=1 时自动在向导区文字下方画一条演示路线，
// 不依赖后端接口，用于确认小地图渲染正常
if (new URLSearchParams(location.search).has("demoRoute")) {
  drawRoute([
    { id: "demo-1", name: "飞来湖", lng: 113.02, lat: 23.70 },
    { id: "demo-2", name: "清远市博物馆", lng: 113.06, lat: 23.68 },
    { id: "demo-3", name: "笔架山", lng: 113.09, lat: 23.72 }
  ]);
  // 临时诊断：把画布真实尺寸写进标签页标题，不用 F12 也能看到
  setTimeout(() => {
    const box = document.querySelector("#guideMap");
    const canvas = box ? box.querySelector("canvas") : null;
    document.title = canvas
      ? `画布 ${canvas.width}x${canvas.height} 显示 ${canvas.clientWidth}x${canvas.clientHeight} 容器 ${box.clientWidth}x${box.clientHeight}`
      : `没有画布 容器 ${box ? box.clientWidth + "x" + box.clientHeight : "缺失"}`;
  }, 2000);
}
```

> `document.title` 那段是排查用的临时诊断（为了在不打开 F12 的情况下读出画布尺寸），确认修复后可删除。
