> 全程只用「路演助手」面板操作：S1 灵感来源、S2 架构图、S3–S8 页面批注、S9 技术亮点、S10 收尾页。

## S1　0:00–0:40　开场｜灵感来源

【点 S1，打开「灵感来源 · 三个社会痛点」】

各位评委老师上午好，我们做的是清远社区共享地图。

先说这张图。【指右上角】这是我 2025 年 8 月用易制地图手工标的第一版。那会儿我刚当助班，想把踩过的店、走过的路分享给刚入学的新同学。但表格发出去就停在那一版了——没人接着改，也没办法按位置查。

后来我想明白一件事：真正有用的不是一份商家名单，而是一张大家都能补充、都能核验的地图。今天这个项目就是从这儿来的。

## S2　0:40–2:00　整体架构

【关掉灵感页，点 S2 打开架构图】

先看整体，三层：上面是入口，中间是服务，下面是数据。

入口有三个：网页端是这次参赛的主体，打开就能用；管理后台是独立页面；鸿蒙端工程已经入库，还没上线，这次不演示。

中间这层是 Cloudflare Pages Functions。没有框架，一个入口文件路由到 70 多个 REST 接口。网页端和鸿蒙端用同一套接口，多端同步只差一个 since 增量参数。

下面这块：D1 是 SQLite，26 个迁移脚本管表结构演进；R2 存图片；高德负责地址核验，智谱负责推荐，华为负责推送。

为什么这么选——全 Serverless，不买服务器、不做运维，密钥全部走 secrets 不进代码库。对我们这种要长期跑下去的项目，这是最实际的方案。

数据流走一遍就清楚了：用户提交一个点位，接口先判重、再调高德核验，通过就写进 D1，图片进 R2；前台拉一次列表，点评条数和均分是子查询一起带出来的，不需要前端再拼一次。

## S3　2:00–3:40　浏览与热门榜

【关架构图，回到主页地图】

这是首页，58 个点位、六大分类，图钉颜色就是分类。

【点「美食」筛选】筛选不是前端过滤，点下去就带参数请求后端，地图和列表一起刷新。

【搜索框输入「鸡」】搜索也一样，走 SQL 匹配名称和简介；输入停 250 毫秒才发请求，不会每敲一个字打一次接口。

右边是热门榜。排序不看时间，看综合热度：点赞算 1 分，点评算 2 分，导航算 2 分。愿意点导航的人，说明他真的去了——这种信号最值钱。

卡片没有图的时候用分类色渐变占位，不会出现一排灰块；加载时先出骨架屏，翻页不会跳一下空白。

【点第一张卡片】比如这家，直接进详情。

## S4　3:40–5:00　详情与匿名点评

【详情面板已展开】

注意它没有弹窗。左边的介绍区就地换成详情，右边地图还在、图钉高亮——从列表点进来不会丢掉「这是哪儿」的位置感。

评分和点评条数跟列表一起返回，不用再发一次请求。点评是「一人一店一条」，再提交就是修改，不会刷屏。

【勾选匿名，发一条点评】

这里有个我们比较在意的设计：匿名点评，后端根本不返回作者字段——没有 user_id、没有昵称、没有头像。不是前端藏起来，是接口里就没有。想反查也查不到。

## S5　5:00–6:20　提交与自动核验

【点「添加一个地点」】

提交是这套系统自动化的关键。名称、地址、分类、标签、简介，可以传多图。

【地址框输入「飞来湖」，点「搜索并定位」】

地址搜索调高德，选中的坐标填进表单。提交时后端再拿名称去高德 POI 里比对：命中就直接上线，坐标按 POI 结果校正——不需要人工一条条审。

防脏数据有三道：同名同分类、或者坐标差不到 0.001 度，直接判重；每条提交带一个 client_token，网络重发也只入库一次；断网时先进本地队列，联网自动补传。

## S6　6:20–8:10　AI 向导与路线

【关弹窗，滚到 AI 向导区】

这一段是重点。Lumina 是我们的 AI 向导。

【点季节按钮，或输入「周末带孩子去哪玩」】

【等待时】它在调模型，一般三到八秒。这段等待我先说机制：相同的问题、相近的视野，24 小时内直接复用缓存——热门问题不烧配额，也不让评委干等。

【结果出来】它给一段中文推荐，同时把提到的点位在地图上高亮；下面这条小地图是路线，按最近的点依次连起来，走的是真实道路，不是直线。

【点「编辑路线」】不满意可以改：上下调顺序、删掉不想去的、再加一个；保存后主地图上的橙色路线跟着重画。

推荐结果还会存在本地：刷新、或者误关了页面，文字、高亮和路线都还在，不用重新调一次模型。

模型这边做了降级：主模型限流就切备用，25 秒还不回就中断，页面不会卡死。

## S8　9:40–10:40　应急地图

【点右下角「应急」】

最后一个功能，也是我们觉得最该做的：应急地图。

【点「医院」】定位之后搜三公里内的医院、警察局、消防和避难所，彩色标记，点一下直接导航。

下面这条求救信息带定位链接，可以复制发出去；110、120、119 直接拨。联系人只存在这台手机的本地存储里，不上传——应急场景更不该拿隐私换方便。

## S9　10:40–11:30　技术亮点

【点 S9，打开技术亮点页】

技术上有六件事我想单独说。

第一，高德 POI 自动核验，把审核成本从人转到机器。

第二，匿名点评在接口层脱敏，刚才演示过。

第三，弱网不丢数据：幂等、离线队列、增量同步，三样一起上。

第四，AI 推荐做了工程化：缓存、降级、超时、暂存恢复。

第五，导航埋点用 sendBeacon，不阻塞跳转，热度才算得准。

第六，我们自己写了一个本地后端模拟器——线上同一套 API 代码直接跑在 Node 上，用 node:sqlite 模拟 D1、文件系统模拟 R2。没有云账号也能把全链路跑通，开发即测试。
