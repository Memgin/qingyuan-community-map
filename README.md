# 清远社区共享地图

一个面向清远本地生活的**社区共建地图**：居民可以提交身边的好去处，系统自动核验地址，其他人可以在地图上发现、收藏、点赞，也可以用自然语言问 AI「附近有什么好玩的」。

- 在线地址：https://qymap.pages.dev
- 管理后台：https://qymap.pages.dev/admin.html

---

## 功能特性

### 浏览与发现
- **地图浏览**：高德地图展示全部点位，分类筛选、点击定位、一键导航
- **热门地点榜**：主页列表按**综合热度**排序（点赞×1 + 点评×2 + 导航×2），卡片显示 🔥 热度分；封面图缺失时用分类色渐变占位
- **最近加入页**：`recent.html` 按时间倒序展示全部点位，带分类筛选与评分入口
- **全部地点页**：`all.html` 网格展示所有点位，支持分类筛选，点击卡片跳回地图自动定位
- **后端真分页**：列表按页取数据，翻页不卡顿
- **后端搜索**：关键词由 SQL 匹配**名称、简介与子标签**，输入有 250ms 防抖
- **分类筛选**：景点 / 美食 / 商圈 / 医疗 / 校园 / 交通，筛选交由后端完成
- **详情就地面板**：点击详情不再弹窗，左侧 hero 区域就地切换为详情页（评分、点评、发表表单），**右侧地图保留**定位显示，对应图钉高亮区分
- **导航点击统计**：跳转高德前 `sendBeacon` 上报（不阻塞跳转），导航次数计入综合热度，导航多的地点更靠前

### 提交与核验
- **提交点位**：填写名称、地址、简介，支持地图选点与**多图上传**（最多 10 张、总共 20MB；第一张作封面，其余进照片墙）
- **高德自动核验**：名称命中高德 POI 即**自动上线**，无需人工审核；坐标由高德结果自动校正，用户不必精确点选
- **重复拦截**：同名同分类、或坐标距离小于 0.001 度会被判为重复提交

### 子集分类（自定义子标签）
- **六大分类下自由细分**：每个点位可挂最多 5 个子标签（如美食下的「早茶 / 烧肉粽 / 河鲜」），一个地点可拥有多个
- **创建即沉淀**：提交表单的标签建议来自该分类下现存标签聚合（`/api/tags` 按使用次数排序）+ 预设建议 + 自定义输入，用户输入新标签即「创建」子集分类
- **点击即筛选**：卡片 / 弹窗 / 详情上的标签可点击，按子标签筛选列表（后端 `tag` 参数精确匹配），筛选状态以可取消的 chip 展示
- **编辑与管理**：点位作者在编辑弹窗以 chips 编辑器增删（单个 × 删除 / 回车逗号添加 / 重复与超限就地提示）；管理员在后台全部点位表格**行内编辑**（失焦即保存）
- **增量同步**：子标签变更更新 `updated_at`，App 端自动同步

### 互动
- **点赞 / 举报**：登录用户按账号记录，网页端与 App 状态一致
- **我的提交**：查看自己提交的点位及其审核状态
- **位置纠偏**：发现点位坐标偏了？登录后在地图弹窗点「位置纠偏」，把蓝色标记拖到正确位置提交，管理员确认后全端生效
- **社区照片墙**：详情面板以 **Carousel 自动轮播**展示社区照片（触摸滑动 / 圆点导航 / 点击放大灯箱），任何登录用户可「补图」，上传后轮播自动刷新

### 私人地图
- **多地图 + 收藏选择器**：创建多张主题地图；收藏时多图弹出选择器（可当场新建），重复收藏有提示，卡片显示「已收藏 ✓」
- **地图详情**：点地图名展开——名称输入框就地改名、点位清单（主地图高亮 / 移除）、**顺路规划**（收藏点位串成路线画在小地图）、删除
- **回收站**：删除为软删除，保留 30 天可恢复 / 彻底删除，过期自动清理
- **多人协作**：主人按用户名 / 昵称添加协作者（昵称撞名出候选列表），双方共同编辑；协作者不能删图 / 分享 / 管理成员
- **只读分享**：生成 `shared.html?t=令牌` 只读链接（仅暴露地图名与点位，不含任何个人信息），可取消分享令牌立即失效
- **AI 建图**：输入主题，AI 从已上线点位挑 2-8 个自动建私人地图（复用推荐的安全基线）
- **应急地图**：🚨 一键定位搜索附近 3 公里的警察局 / 医院 / 消防 / 避难所（彩色标记 + 导航），求救信息带定位链接，可拨 110/120/119、给预设联系人发定位短信（联系人只存本机）

### 大众点评与评分
- **评分展示**：列表卡片、地图弹窗、全部地点页均显示星级 + 均分 + 点评条数（列表接口子查询聚合，无二次请求）
- **地点详情弹窗**：封面图 + 评分摘要 + 全部点评列表 + 发表/修改点评
- **一人一店一条**：再次提交即修改原点评，可随时切换匿名 / 实名；作者本人可删除
- **匿名点评**：显示「匿名用户」+ 模糊头像；后端对该条记录**不返回任何作者字段**（无 user_id / 昵称 / 头像），无法反查账号
- **实名点评**：展示昵称 + 头像，点击头像进入该用户公开主页（只聚合非匿名点评）
- **个人资料**：顶栏「⚙ 我的资料」设置昵称（2-24 字）与头像（≤2MB，复用上传接口），实名点评同步展示
- **写入限流**：每账号每小时 20 条

### 账号与安全
- **注册页改版**（独立页 `register.html`）：用户名 + 手机号（11 位，全库唯一，即时查重）+ 密码 + 确认密码（一致性即时提示、可见性切换、三档强度条）；用户名输入 600ms 防抖实时查重（`/api/auth/check-username`），单字立即提醒；注册后统一转小写保存（登录兼容旧大写账号）
- **人机验证**：线上用 Cloudflare Turnstile（`TURNSTILE_SECRET`）；未配置（本地模拟环境）仅靠 IP 注册频控兜底（同 IP 24h 3 个账号）；App 原生注册走免验证限额
- **演示模式对齐**：本地演示与真实后端行为一致——账号必须存在且密码正确，不再任意建号（演示账号统一密码 `demo123456`）
- **手机号自助找回密码**：登录弹窗「忘记密码」→ 用户名 + 手机号 + 新密码，核验通过立即改密并**作废全部旧会话**；按 IP 限流 5 次/时、统一错误话术不暴露账号存在；未绑手机号的账号仍走原「人工审核找回」通道
- **个人资料加固**：昵称剔除零宽/控制字符、保留字黑名单（admin/官方/客服…）、不得与他人用户名重复、全库查重、改名写入历史表；头像经 `?purpose=avatar` 强制 ≤2MB + 文件头校验 + 最小分辨率 64×64，只允许站内地址，支持「移除头像」；资料保存限流 10 次/时
- **隐私保护**：点评、照片墙、公开主页、协作者接口一律不再返回 `username`，对外只展示「昵称 + 用户 ID」；公开主页注册时间只到日期
- **密码策略**：仅注册和设置新密码时校验（8 位以上含字母数字），登录只做比对，不追溯旧密码
- **找回密码（人工通道，全自动闭环）**：重置申请 → 管理员审批 → 密码重置为 `12345` 并踢掉全部会话 → Push Kit 推送临时密码 → 强制改密窗（未改密前写操作一律 403）；**设备送达预检**：无绑定推送设备的账号拒绝自动重置，转人工核验

### 消息推送
- **华为 Push Kit**：审核结果（通过/驳回）、密码重置通知实时推送到用户所有设备
- 设备在登录时上报 Push Token（`POST /api/push-token`），退出登录时自动注销

### AI 智能推荐
- **Lumina 文创 IP 形象**：本项目文创 IP「霓窗仔」的化身——3D 模型（GLB 经 Draco 压缩 + 纹理 WebP，42.98MB → 3.48MB）立于向导面板右侧，自动旋转、可拖拽交互
- 用自然语言提问（如「周末带孩子去哪玩」），返回中文推荐文案并**在地图上高亮对应点位**
- 向导区下方内嵌**路线小地图**：推荐点位按最近邻贪心排序 + 序号标记
- **路线贴合道路**：逐段调用高德驾车路径规划（`AMap.Driving`）取真实道路点串，向导区小地图与**主地图自动加载**的路线均为沿路实线；单段失败只画该段短直线兜底，相邻点位过近（<120m）跳过规划
- **季节推荐**：按当前月份把应季主题（春赏花 / 夏避暑 / 秋登高 / 冬食补）排最前并高亮，一键触发推荐
- **结果缓存**：相同需求 + 相近视野（约 1km 精度）24 小时内直接复用缓存结果，不调模型、不计限流额度——热门问题零配额消耗
- **推荐结果暂存**：推荐内容存入本地，**强制刷新后自动恢复**（文字 + 高亮 + 路线），主动清除才丢弃
- **路线编辑器**：「编辑路线」→ 左列编辑面板（↑↓ 调序 / 移除 / 添加点位）实时同步向导区与主地图路线，打开时与向导区同序，保存后暂存持久化
- 接入智谱 `glm-4.7-flash`，主模型限流时自动降级到备用模型，25 秒超时保护

### 管理后台
标签页布局，六个板块，密钥在会话内自动记忆：
- **① 待审核点位**：通过 / 拒绝
- **② 全部点位**：表格化布局，按名称/地址搜索、**彩色圆点分类筛选**、状态筛选、**行内修改分类与子标签**（失焦即保存并触发增量同步）、**数据概览图表**（Chart.js：分类分布 + 热度 Top 10 三段堆叠）、删除违规内容（级联清理点评 / 点赞 / 举报 / 收藏）
- **③ 举报处理**
- **④ 账号与密码**：密码重置申请审批（一键同意并推送临时密码；无法安全送达的可删除转人工）、手动重置密码
- **⑤ 位置纠偏**：审批用户提交的坐标修正（新旧坐标对照，同意即移动点位）
- **⑥ 诊断工具**：高德接口自检（不暴露 Key）

### 界面
- **苹果风设计语言**：SF 系统字体栈、三档圆角令牌（10/14/22px）、柔和多层阴影、胶囊按钮、毛玻璃 toast、克制的莫兰迪分类色系（低饱和在地图底色上耐看不刺眼）
- **图标系统**：全站 emoji 由 [Iconify](https://iconify.design/)（Phosphor 图标集，CDN 按需加载）替代——分类图标、互动行、应急、导航、按钮统一线性风格
- **地图图钉**：Google Maps 风格水滴形——分类色圆头 + 白图标 + 正下尖角 + 落地投影，高亮态珊瑚色脉冲光环；莫兰迪配色与图例 / 卡片 / 图表全局一致
- **动画与骨架屏**：Animate.css 动画基座；列表加载显示微光骨架占位卡（翻页 / 筛选 / 搜索生效）
- **详情照片轮播**：社区照片 Carousel 自动轮播（4s/张、触摸滑动、圆点导航）+ 点击放大灯箱（全屏查看 / 左右切换 / Esc 关闭）
- **移动端重排**：手机动线 flex+order 布局——LOCAL/01 品牌区（压缩版）→ 详情 / 路线编辑面板（打开时贴地图上方）→ 大地图（62svh）→ 热门地点 → AI 向导 → 私人地图；季节按钮窄屏竖排每行一个；私人地图面板与 AI 向导同款头部左右分栏布局
- **液态玻璃**：顶栏接入 [simple-liquid-glass](https://github.com/lucaperullo/simple-liquid-glass)（CDN 锁定 5.6.0，Web Component 纯视觉层，`pointer-events: none` 不拦截交互，CDN 失败自动降级为半透明底色）
- **地点卡片**：封面锚点（无图用分类色渐变 + 图标占位）+ 评分元信息行 + 子标签行 + 聚合互动行；次要操作（收藏/补图/编辑/举报/删除）收进「⋯」菜单

### 多端同步与离线能力
| 能力 | 说明 |
| --- | --- |
| 增量同步 | `GET /api/spots?since=<时间>` 只返回该时间点之后新增或变更的点位 |
| 离线提交幂等 | 请求体带 `client_token`，同一条提交重复发送只写入一次 |
| 离线提交队列 | 断网提交先入队，联网或下次启动自动重发 |
| 离线缓存兜底 | 列表与地图数据缓存到本地，断网时展示缓存而非空白 |
| 新点位提示 | 定时增量轮询，发现新点位提示刷新，不打断当前浏览 |

## 技术架构

```
┌──────────────┐   ┌─────────────────┐   ┌──────────────┐
│   网页端      │   │  HarmonyOS App  │   │   管理后台    │
│ 原生 HTML/JS │   │ qymap-harmony/  │   │  admin.html  │
└──────┬───────┘   └────────┬────────┘   └──────┬───────┘
       └────────────────────┼───────────────────┘
                            │ HTTPS / JSON
              ┌─────────────▼──────────────┐
              │ Cloudflare Pages Functions │
              ├────────────────────────────┤
              │ D1（SQLite） 点位 / 用户    │
              │ R2           图片存储       │
              │ 高德 REST    地址核验       │
              │ 智谱 API     AI 推荐        │
              │ 华为 Push Kit 消息推送     │
              └────────────────────────────┘
```

| 层 | 技术 |
| --- | --- |
| 网页端 | 原生 HTML / CSS / JavaScript，高德地图 JS API，model-viewer（3D 文创 IP） |
| 鸿蒙端 | ArkTS / ArkUI（DevEco Studio 工程 `qymap-harmony/`） |
| 后端 | Cloudflare Pages Functions（无框架，原生 `Request` / `Response`） |
| 数据库 | Cloudflare D1（SQLite） |
| 图片 | Cloudflare R2 |
| 地址核验 | 高德 Web 服务 REST（逆地理编码 + 关键词检索） |
| AI | 智谱 `glm-4.7-flash`（OpenAI 兼容格式） |
| 部署 | Wrangler CLI |

## 本地运行与部署

### 1. 安装依赖

```bash
npm install
```

### 2. 配置密钥（全部存为 Pages secrets，不写入代码）

```bash
npx wrangler pages secret put ADMIN_TOKEN    # 管理后台口令
npx wrangler pages secret put AMAP_WEB_KEY   # 高德「Web服务」类型 Key（非 Web端/JS）
npx wrangler pages secret put AI_API_URL     # AI 接口地址（可选）
npx wrangler pages secret put AI_API_KEY     # AI 接口密钥（可选）
npx wrangler pages secret put AI_MODEL       # 模型名（可选，默认 glm-4.7-flash）
npx wrangler pages secret put PUSH_APP_ID        # 华为推送 App ID（可选，不配则推送静默关闭）
npx wrangler pages secret put PUSH_CLIENT_ID     # 华为推送 Client ID
npx wrangler pages secret put PUSH_CLIENT_SECRET # 华为推送 Client Secret
```

> ⚠️ 高德 Key 必须选 **Web服务** 类型。「Web端（JS API）」类型无法调用 REST 接口，会导致自动核验永远失败。

### 3. 初始化数据库

```bash
npx wrangler d1 execute qingyuan-community-map --remote --file=worker/schema.sql
```

迁移脚本统一放在 `migrations/` 目录，按时间 / 主题顺序执行（早期：auth → owner → moderation → quotas → category-school；近期：security → registration → pwd-flow → push → photos → correction → reviews → ai-cache → nav-stats → share → trash → collab → spots-tags → profile-hardening → phone）。`worker/` 保留独立 Worker 工程本体（`src/` + `wrangler.toml` + `schema.sql`）。

### 4. 部署

```bash
npx wrangler pages deploy . --project-name qymap --branch main
```

## API 接口

基础路径：`https://qymap.pages.dev/api`

### 点位

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/spots?page=&limit=&category=&q=&tag=&since=&sort=&fields=` | 点位列表（附带 `avg_rating` / `review_count` / `hot_score` / `tags`，未迁移旧库自动降级）；`tag=` 子标签筛选、`sort=hot` 综合热度、`sort=likes` 点赞、默认时间序；`fields=map` 返回图钉轻量字段 |
| GET | `/tags?category=` | 聚合该分类下所有已上线点位的子标签（去重 + 使用次数排序），供标签建议与筛选展示 |
| POST | `/spots` | 提交点位（需登录 + `X-Owner-Token`），支持 `client_token` 幂等 |
| DELETE | `/spots/:id` | 删除自己提交的点位 |
| POST | `/spots/:id/like` | 点赞（登录时按账号记录） |
| POST | `/spots/:id/report` | 举报 |
| POST | `/spots/:id/correction` | 位置纠偏（需登录，提交坐标修正建议） |
| POST | `/spots/:id/navigate` | 导航点击埋点（公开，`sendBeacon` 上报；IP 限流 60 次/小时，计入综合热度） |
| GET / POST | `/spots/:id/reviews` | 点评列表 + 评分统计 / 发表或修改点评（UPSERT，一人一店一条，需登录） |
| DELETE | `/reviews/:id` | 删除自己的点评（匿名点评仅作者可删） |
| GET | `/my-spots` | 我提交的点位 |

### 用户

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/auth/register` `/auth/login` `/auth/logout` | 注册（手机号必填 + 人机验证双模）/ 登录 / 退出；用户名统一小写 |
| POST | `/auth/profile` | 设置昵称（保留字/查重/净化）与头像（站内地址）、换绑手机号（需登录） |
| GET | `/auth/check-username`、`/auth/check-phone` | 用户名 / 手机号占用检查（注册页防抖调用） |
| GET | `/users/:id/profile` | 用户公开主页（仅聚合非匿名点评，响应不含 username） |
| GET | `/auth/me` | 当前用户（含 `mustChangePassword` 标志、昵称头像、脱敏手机号） |
| POST | `/auth/change-password` | 设置新密码（临时密码登录后强制调用） |
| POST | `/auth/reset-password` | 手机号自助找回：`{ username, phone, newPassword }`（IP 限流 5 次/时，成功后作废全部旧会话） |

## 安全说明

- 所有密钥（高德 Key、AI 密钥、管理员口令、推送密钥）均以 **Pages secrets** 形式存放，代码中只以 `env.XXX` 引用，不入库
- 用户密码使用 **PBKDF2 + 随机盐** 哈希存储，不存明文
- **临时密码安全模型**：重置密码统一为公开值 `12345`，但必须满足「该账号有已绑定的推送设备」才允许自动重置——保证公开密码只会被推送到失主本人的历史登录设备，攻击者无法凭用户名接管账号；无设备的账号走管理员人工核验 + 线下告知
- **登录防护**：连续失败锁定、按 IP 的注册频率限制、登录尝试记录
- `index.html` 中的高德 **Web端 JS Key** 是前端必需的公开值，**请在高德控制台为其配置 referer 域名白名单与每日配额上限**，避免被他人盗用产生费用
